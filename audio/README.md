# 声音素材

放在 `public/` 下，Vite 会原样提供，代码里用 `/audio/field/xxx.ogg` 加载。

- `field/`：现实世界录音（Freesound 下载 + 作者自录）
- `generated/`：生成的声音（Tone.js 离线渲染、合成音色、循环底）

文件名建议：`场景_内容_序号.ogg`，例如 `bridge_under-traffic_01.ogg`。
格式优先 `.ogg` / `.mp3`，循环素材剪成无缝循环，单个 ≤ 2 MB。
